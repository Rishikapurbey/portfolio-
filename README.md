# Portfolio

Personal portfolio of Rishika Purbey, designed as a cinematic scroll story: opening titles, scenes that reveal as you scroll, and projects presented as film posters.

## Stack

React 19, TypeScript and Vite. Plain CSS, no UI libraries.

## Running locally

```bash
npm install
npm run dev
```

## Editing content

All text, projects, experience and stats live in `src/data/profile.ts`.
