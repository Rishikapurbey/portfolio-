# Portfolio

**Live:** [rishika-purbey.vercel.app](https://rishika-purbey.vercel.app)

Personal portfolio of Rishika Purbey, designed around a game of chess: an animated board in the hero, sections named after moves, and a score sheet that follows you down the page.

## Stack

React 19, TypeScript and Vite. Plain CSS, no UI libraries. Deployed on Vercel; every push to `main` goes live.

## Running locally

```bash
npm install
npm run dev
```

## Editing content

All text, projects, experience and stats live in `src/data/profile.ts`.
